# Soapy SDR plugins for OsmoSDR devices

## Dependencies

* Boost C++ libraries
* SoapySDR - https://github.com/pothosware/SoapySDR/wiki
* SDR device libraries for osmosdr, mirisdr, rfspace, airspy
